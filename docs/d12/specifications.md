# D12 — Specifications

## Technical specifications

| Item | Specification |
|------|---------------|
| Operating system | Linux, Chinese / English interface |
| Setup | Touchscreen, mobile web page or app |
| CPU | 32-bit RISC 1 GHz, 1 TOPS NPU (AI engine) |
| Memory | 2 Gb DDR3, 128 Mb NAND flash |
| Video input | 5 × AHD 1080p / 720p cameras |
| Display | Built-in 10.1-inch 720p touchscreen |
| Video format | H.264, PAL / NTSC |
| Main stream | 1920 × 1080 or 1280 × 720, 1–25 fps, 256 Kbps – 6 Mbps |
| Sub stream | 720 × 576 / 720 × 480 / 640 × 360, 1–15 fps, 256 Kbps – 2 Mbps |
| Recording | Automatic by default; ignition, alarm and time-lapse recording supported |
| Audio | Built-in microphone and speaker (≤ 8 Ω, 1.5 W), AAC / G.711A |
| Alarm inputs | 5: ACC, left turn, right turn, input, SOS |
| Outputs | 3 low-level outputs (optional), e.g. for a relay for remote fuel / power cut-off |
| Serial ports | 2 × RS232 (for card readers, fuel sensors, etc.) |
| 4G | CAT4. Global version: TDD-LTE B38/B40/B41, FDD-LTE B1/B3/B7/B8/B20/B28, WCDMA B1/B8 |
| Wi-Fi | 802.11 b/g/n, 2.4 GHz (internal antenna) |
| Positioning | Built-in GPS / BeiDou |
| G-sensor | Built-in 3-axis accelerometer |
| Storage | SD card up to 512 GB; optional mSATA hard drive |
| SIM | 1 SIM card slot |
| Upgrade | SD card or FTP remote upgrade |
| Input voltage | 9 V to 36 V DC, with overload, under-voltage, short-circuit and reverse-polarity protection |
| Power consumption | Under 2 W in normal use (without accessories) |
| Power-loss protection | Optional super capacitors keep recordings intact |
| Operating temperature | −20 °C to +70 °C |
| Humidity | 10 % to 90 % |
| Protocols | JT/T808-2013, JT/T808-2019, JT/T1078 |
| Size | 25 × 17 × 3.5 cm |
| Weight | 1.45 kg |

## AI functions

| Type | Detects |
|------|---------|
| **ADAS** | Forward collision, lane departure, pedestrians, following distance |
| **DMS** | Fatigue (eyes closed, yawning), phone use, smoking, distraction, seat belt, face covered, face recognition |
| **BSD** | Front, rear, left and right blind spots (needs external cameras) |

## Screen status icons

The icons at the **top right** of the D12 screen show the device status. A **bright** icon means OK; a **grey** icon means there's a problem.

| Icon | Bright | Grey |
|------|--------|------|
| **4G** | 4G connected (bars show signal strength) | No 4G signal |
| **Platform** | Connected to Traqcare | Not connected to the platform |
| **Wi-Fi** | Wi-Fi on (hotspot or client mode) | Wi-Fi off |
| **SD card** | SD card detected | SD card not detected or faulty |
| **GPS** | GPS location found | No GPS location |
