# A6 — 4G Cloud Dashcam

The **A6** is a 4G dashcam that records the road ahead in **2K** and the rear in **720P** by default (the rear camera supports **1080P**). It sends its live location and video to **Traqcare** over 4G. You set it up with the free **Cloud Spirit** app on your phone.

| Part | What it's for |
|------|---------------|
| **Power button (⏻)** | Press **twice quickly** to turn on the A6's Wi-Fi for setup. |
| **SOS button** | Press in an emergency to send an SOS alarm. |
| **Light bar** | Shows that the A6 is working, connected and has a GPS position. |

## What it does

| Feature | What you get |
|---------|--------------|
| **Video** | Front **2K** camera and rear camera, **720P** by default and up to **1080P**, recorded with sound to a memory card (up to 512 GB). |
| **Live video** | Watch both cameras live in Traqcare or the Cloud Spirit app. |
| **Tracking** | GPS + BeiDou location and route playback in Traqcare. |
| **Parking monitoring** | Sentry Mode, collision wake-up and time-lapse recording while parked. |
| **Wi-Fi** | Built-in Wi-Fi hotspot for setup with your phone. |
| **Low power** | Deep sleep when the ignition is off (3 mA or less), so it won't drain the battery. |
| **Updates** | Software updates by memory card or over the air. |
