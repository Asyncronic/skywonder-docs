# A6 — Specifications

| Item | Specification |
|------|---------------|
| Processor | Allwinner V853: single-core Cortex-A7 @ 1.2 GHz + single-core RISC-V @ 600 MHz |
| Memory | DDR3 256 MB |
| Storage (ROM) | NOR 256 Mb |
| Operating system | Linux |
| Cameras | Front MIPI 2K, rear AHD (720P by default, supports 1080P) |
| Frame rate | Front 2K @ 25 fps |
| Video compression | H.264 |
| Video file format | TS |
| Audio | External microphone input; sound recorded with the video |
| Memory card | TF (microSD), up to 512 GB |
| Positioning | GPS + BeiDou dual mode |
| Wi-Fi | Built-in 2.4 GHz hotspot |
| 4G | CAT1, 2G/3G/4G. Bands: B1, B3, B5, B8, B38, B39, B40, B41 |
| Sensor | 3-axis G-sensor with collision detection |
| Buttons | **Power** (⏻) and **SOS** |
| Speaker | External, 8 Ω 1.5 W |
| Indicator | LED light bar showing working, network and positioning status |
| Power supply | 12 V DC (works from 12 V to 24 V) |
| Ignition detection | ACC on / off |
| Power on / off | Switches on with B+ (constant power); deep sleep when ACC is off (3 mA or less) |
| Operating temperature | −20 °C to +70 °C |
| Software updates | TF card or over the air (OTA) |
| Protocol | JT/T808 (Traqcare port 5101) |

:::note 4G bands
Check that your mobile operator uses one of the supported 4G bands (B1, B3, B5, B8, B38, B39, B40, B41) before you choose a SIM card.
:::
