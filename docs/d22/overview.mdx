# D22 — 2-Channel 4G Dash Camera

The **D22** is a compact 4G dashcam with **two built-in 1080p cameras**. It records to a memory card, sends its live location and video to **Traqcare** over 4G, and (on AI versions) warns the driver about fatigue, phone use, distraction and collision risks.

:::info The app calls it "WD02"
In the **Traqcam Connect** app the D22 shows up as **WD02**. The app lists only the D9, WD02 and S202, and the D22 is set up the same way as the WD02, so the app uses that name. The D22 is a different device; you don't need to change anything.
:::

## What it does

| Feature | What you get |
|---------|--------------|
| **Video** | 2 cameras, 1080p, recorded with sound to a memory card (TF card). Watch live and recorded video in Traqcare. |
| **Tracking** | GPS + BeiDou location, sent to Traqcare over 4G. |
| **Wi-Fi** | The D22 creates its own Wi-Fi so you can set it up with your phone. |
| **SOS button** | One press sends an emergency alarm to Traqcare. |
| **Voice** | Built-in speaker and microphone. |
| **AI (optional)** | **DMS** watches the driver (fatigue, phone, smoking, distraction, seat belt). **ADAS** watches the road (lane departure, forward collision, pedestrians, following too close). |
| **Power safety** | A built-in super capacitor protects the last video file if power is cut suddenly. |

The AI features only work on a D22 ordered **with DMS + ADAS**.
