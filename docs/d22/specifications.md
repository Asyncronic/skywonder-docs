# D22 — Specifications

## Main features

- H.265 / H.264 video encoding, which saves storage space and mobile data.
- 2 channels of 1080p @ 25 fps (encoding up to 1080p @ 60 fps).
- GPS + BeiDou dual-mode positioning.
- 1 TF (microSD) card slot.
- Super capacitor that protects video files if power is lost suddenly.
- 4G with global frequency bands.
- Wi-Fi hotspot for setup with the mobile app.
- Built-in speaker and microphone, with two-way voice between the dashcam and the platform.
- One-key SOS emergency alarm.
- Low-power standby with remote wake-up and vibration wake-up.
- Starts in under 10 seconds.

|------|-----------|
